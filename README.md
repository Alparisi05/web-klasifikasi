# ♻️ Sortfy - Sistem Klasifikasi Sampah Berbasis Web

![Sortfy Banner](./assets/banner.png)

## 📌 Tentang Proyek

Sortfy adalah aplikasi web berbasis Artificial Intelligence yang membantu pengguna mengidentifikasi jenis sampah melalui gambar yang diunggah. Sistem akan melakukan klasifikasi secara otomatis dan memberikan rekomendasi pengelolaan sampah yang sesuai, seperti daur ulang, penggunaan kembali, atau pembuangan yang aman.

Proyek ini dikembangkan untuk mendukung peningkatan kesadaran masyarakat terhadap pentingnya pemilahan sampah dan pengelolaan lingkungan yang lebih bertanggung jawab.

## 📖 Cara Menggunakan

### 1. Buka Website

Kunjungi:

https://sortfy-klasifikasi-sampah.netlify.app/

### 2. Upload Gambar

Klik tombol **Upload Image** dan pilih foto sampah.

### 3. Tunggu Proses Prediksi

Sistem AI akan menganalisis gambar yang diunggah.

### 4. Lihat Hasil

Website akan menampilkan:

- Jenis sampah
- Tingkat kepercayaan prediksi
- Rekomendasi pengelolaan sampah
